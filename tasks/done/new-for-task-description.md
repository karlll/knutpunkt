# Add a better template for the task description

## Overview

Currently, the template for the description text area in the TaskDialog is very brief. It should be replaced by the template:

```markdown

## Overview

[A brief overview] 

## Requirements

- [requirement 1]
- [requirement 2]

## Acceptance Criteria

- [] [criteria 1]
- [] [criteria 2]
```
