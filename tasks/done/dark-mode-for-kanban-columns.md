# Dark Mode harmonized colors for the Kanban columns

## Overview

Currently, the background colors for the columns are the same in light mode and dark mode. In dark mode the colors are not consistent with a dark "theme".

## Requirements

- Show suitable, dark mode consistent colors for the columns when the dark mode is active. The current colors should be shown in light mode
- The top label for the column ("Planned", "Ongoing", etc) should also have a color that is correctly contrasting to the background (valid for both dark and light mode)

## Acceptance Criteria

- [ ] In dark mode: the colors are harmonized and consistent to dark mode
- [ ] In light mode: the colors are harmonized and consistent to light mode
